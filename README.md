# TOEIC 850

Ứng dụng luyện thi TOEIC chạy trên trình duyệt: từ vựng (1000 từ, chia nhóm, có phiên âm), ngữ pháp Part 5, đọc hiểu Part 6–7, nghe Part 1–4, chép chính tả, thi thử, hướng dẫn chiến lược từng Part và hỏi AI.

## Chạy
Mở trực tiếp `index.html` hoặc xem trên GitHub Pages. Giữ `vocab.js` cùng thư mục với `index.html`.

Tiến độ lưu trong trình duyệt. "Hỏi AI" dùng API key do người dùng tự nhập, key không được lưu trong mã nguồn.
